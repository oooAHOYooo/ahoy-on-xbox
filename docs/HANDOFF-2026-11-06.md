## Shared interface contract

The canonical contract is `docs/TV-UI-CONTRACT.md` in this checkout and `../ahoy-on-tv/docs/TV-UI-CONTRACT.md` in the sibling checkout. The copies were compared and matched. The sibling file is tracked in `ahoy-on-tv`; there was no sibling working-tree change to commit during the prior verification.

The interface rules are:

1. Use the four sections in the same order and with the same labels: Live TV, On Demand, Music, Podcasts.
2. Keep the full-screen media/artwork stage, left brand mark, centered section navigation, right live/account status, lower-left hero metadata, and bottom horizontal content shelf.
3. Make the hero respond to focus/selection. On Live TV, browsing a channel previews it; selecting the channel tunes it.
4. Use pink `#FF0060` for active/focused states, black `#000000` for the stage, charcoal cards around `#141418` and `#1C1C22`, white primary text, and gray secondary text.
5. Keep control semantics aligned while using each platform’s native views and input system. Xbox-only save and account-pairing behavior is not a requirement for Fire TV.

If changing shared labels, action semantics, hierarchy, or tokens, update both contract copies in one coordinated change and state explicitly in the handoff whether both platform implementations were updated. Do not claim shared code components: these are native apps on different UI frameworks, and the current shared layer is a visual/interaction contract.

### Xbox interaction map currently shown in the native UI

- D-pad / left stick: navigate focused tabs and shelf cards.
- A / activation: select a channel or media card; the Live TV channel action tunes its clock-synchronized queue.
- LB / RB: previous/next channel while in Live TV.
- LT / RT: cycle sections.
- B: leave fullscreen, return to Live TV from another section, or wake the guide. It does not close the app at the root screen.
- X: toggle saved state for the current item.
- Y: open Xbox Ahoy ID pairing.
- Fullscreen: the visible hero action toggles `MediaPlayerElement.IsFullWindow`.

The HTML simulator is deliberately a preview aid and has a smaller keyboard mapping: arrows browse cards/sections; Enter selects; X toggles a local demo save state; Y opens a clearly sample pairing dialog; B/Escape closes that dialog. It does not use Xbox APIs or connect to Ahoy ID.
